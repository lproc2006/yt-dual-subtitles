双语字幕助手
首页支持

隐私政策

生效日期：2026 年 8 月 12 日

“双语字幕助手 for YouTube”（以下简称“本扩展”）用于在 YouTube 视频页读取视频字幕，生成双语显示并允许用户导出字幕。开发者不运营用于接收用户数据的服务器，不出售用户数据，也不使用广告、分析统计或用户跟踪功能。

首次打开一个视频时，本扩展需要一次性提取并翻译整段字幕，通常需要 1–3 分钟。该等待时间只反映本地处理或翻译进度，不代表扩展额外收集数据。

1. 处理的数据

本扩展会读取当前 YouTube 视频的标识、标题、字幕语言和字幕文本。这些数据只用于用户正在使用的字幕显示、翻译、缓存和导出功能。

翻译缓存保存在浏览器本地，可能包含视频标识、字幕文本生成的指纹、译文、语言信息和保存时间。启用状态、显示样式和翻译方向等偏好可能由浏览器自身同步到用户登录的浏览器账号，开发者无法访问这些同步数据。

2. 翻译方式

本扩展优先使用浏览器提供的本地翻译能力。使用本地翻译时，字幕文本不会由本扩展发送到第三方翻译服务。

本地翻译不可用或处理失败时，当前视频需要翻译的字幕文本会自动发送到 Google 翻译并接收译文。发送内容不包括浏览器密码、身份验证 Cookie 或完整浏览历史。Google 对收到数据的处理适用其自身的隐私政策和服务条款。

3. 没有字幕的视频

本扩展会尝试连接用户设备上 127.0.0.1:8765 的本机字幕服务，并发送当前视频 ID 和目标语言。本机服务可能调用 yt-dlp 读取用户本机浏览器中的 YouTube Cookie，以便直接向 YouTube 请求视频信息或音频；Cookie 不会发送给扩展开发者，也不会写入字幕缓存。音频和 Whisper 识别均在用户设备上处理，临时音频在任务结束后删除。

本机服务未安装或未运行时，扩展仍可处理带有 YouTube 字幕的视频，但无法为完全没有字幕的视频生成字幕。

4. 数据用途限制

除自动使用 Google 在线翻译以及本机服务直接向 YouTube 请求视频资源外，本扩展不会向开发者或其他第三方传输字幕、浏览活动或用户身份数据。数据不用于广告、信用评估、销售、画像或无关目的，也不会允许人工读取用户字幕。

5. 保存与删除

用户可在扩展面板清除浏览器本地翻译缓存，也可通过浏览器移除扩展以删除扩展存储。用户主动导出的 Markdown 文件由用户自行管理。

6. 权限

  • storage：保存设置和本地翻译缓存。
  • youtube.com：读取当前视频字幕并显示字幕层。
  • translate.googleapis.com：本地翻译不可用时获取在线译文。
  • 127.0.0.1:8765：访问用户设备上的本机字幕服务。

7. 联系与声明

隐私问题可通过 GitHub Issues 提出。本扩展不是 YouTube、Google 或 Microsoft 的官方产品，也未获得这些公司的认可或背书。
