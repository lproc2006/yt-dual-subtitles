# 商店上架文案（2.3.0）

## 名称

双语字幕助手 for YouTube

## 简短说明

YouTube 双语字幕：自动提取并翻译中英文字幕，支持样式调整与 Markdown 导出；首次处理视频通常需等待 1–3 分钟。

## 首屏提醒

**首次处理请耐心等待 1–3 分钟。** 扩展需要一次性提取并翻译整段字幕。完成后，同一视频会优先复用本地缓存。视频长度、字幕数量、网络状况和本机性能会影响实际时间。

## 单一用途

在用户主动打开的 YouTube 视频播放页读取视频字幕，提供中英文翻译、同步显示和字幕文本导出。

## 详细说明

双语字幕助手用于在 YouTube 视频播放页读取作者字幕或 YouTube 自动字幕，并根据实际字幕语言自动选择中译英或英译中。用户可以显示原文与译文对照，或仅显示译文，还可以调整字号、字幕背景和显示预设。

首次打开一个视频时，扩展会一次性提取并翻译整段字幕，通常需要等待 1–3 分钟。处理完成后，同一视频会优先复用浏览器本地缓存，因此再次打开通常更快。视频长度、字幕条数、网络状况和本机性能会影响实际处理时间；缓冲期间请保持视频页面打开。

主要功能：

- 自动读取作者字幕或 YouTube 自动字幕。
- 自动识别中英文，也可手动指定英文→中文或中文→英文。
- 优先使用浏览器本地翻译；本地能力不可用时，自动使用 Google 在线翻译。
- 支持原文与译文对照、仅译文、字号、背景和显示预设。
- 支持把当前字幕导出为 Markdown 原文、译文或双语稿。
- 翻译缓存仅保存在用户浏览器本地，并可从扩展面板一键清除。

视频完全没有作者字幕或自动字幕时，扩展会尝试连接单独安装的本机字幕服务，在用户设备上提取音频并使用 Whisper 识别。配套服务可能通过 yt-dlp 读取本机浏览器中的 YouTube Cookie，以便直接向 YouTube 请求视频资源；Cookie 不会发送给开发者。本机服务未安装时，带有 YouTube 字幕的视频仍可正常使用，无字幕视频则无法生成字幕。

隐私说明：扩展没有账号系统、广告、分析统计或开发者数据服务器。浏览器本地翻译不可用时，当前视频需要翻译的字幕文本会自动发送给 Google 翻译。完整数据处理方式见隐私政策。

本扩展不是 YouTube、Google 或 Microsoft 的官方产品，也未获得这些公司的认可或背书。

## 权限理由

- `storage`：保存启用状态、翻译方向、显示样式和本地翻译缓存。
- `https://www.youtube.com/*`：读取用户当前打开视频的字幕，并在该页面显示字幕层。
- `https://translate.googleapis.com/*`：浏览器本地翻译不可用时，发送当前视频字幕文本并接收译文。
- `http://127.0.0.1:8765/*`：访问用户设备上单独安装的字幕缓存与 Whisper 语音识别服务。

## 数据披露填写建议

- 网站内容：处理当前视频字幕，用于字幕显示、翻译、缓存和用户主动导出。
- 浏览活动：只访问用户主动打开的 YouTube 视频页，用于扩展单一用途；不用于跟踪或分析。
- 身份验证信息：扩展本体不收集、不使用、不传输。可选本机服务可能由 yt-dlp 在用户设备上读取 YouTube Cookie，并只用于直接请求 YouTube 视频资源。
- 个人身份、健康、金融、位置、通信：不收集。
- 第三方共享：浏览器本地翻译不可用时，字幕文本发送给 Google 翻译；除此之外不向开发者或其他第三方发送字幕。
- 数据销售、广告、信用评估：均不使用。
- 远程代码：不使用。所有可执行代码均包含在扩展包内。
