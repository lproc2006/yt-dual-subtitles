# 审核人员说明（2.3.0）

## 测试条件

请使用最新版 Chrome 或 Microsoft Edge，并打开一个带有英文或中文字幕的公开 YouTube 视频。扩展不需要测试账号、付费或登录。

## 重要等待说明

首次打开一个视频时，扩展需要一次性提取并翻译整段字幕，通常需要 1–3 分钟。处理期间扩展面板会显示提取或翻译进度，请保持视频页面打开。处理完成后，同一视频会优先复用本地缓存。

## 带字幕视频测试

1. 安装扩展并打开一个公开的带字幕视频，例如：
   - 英文字幕：https://www.youtube.com/watch?v=v4F1gFy-hqg
   - 中文字幕：https://www.youtube.com/watch?v=0-Rr2iho6CI
2. 保持“启用字幕翻译”开启，等待首次提取和翻译完成。
3. 原文和译文应随视频播放同步显示。
4. 打开扩展面板，切换“双语对照／仅译文”、翻译方向、字号和背景，页面显示应即时更新。
5. 点击“导出为 .md 文件”，应下载当前字幕的 Markdown 文件。
6. 点击“清除本地翻译缓存”，浏览器本地译文缓存应被清除。

## 翻译方式

扩展优先使用浏览器提供的本地翻译能力。本地能力不可用或处理失败时，当前视频需要翻译的字幕文本会自动发送到 `translate.googleapis.com` 并接收译文。该行为已在扩展面板、隐私政策和商店说明中披露。

## 无字幕视频与本机服务

完全没有 YouTube 字幕的视频需要另行安装并运行本机字幕服务。扩展只向 `127.0.0.1:8765` 发送视频 ID 和语言信息；音频提取、Whisper 识别和缓存均在用户设备上完成。本机服务未安装时，这项可选功能不可用，但不影响带字幕视频的核心功能。

部分受限视频、直播或无法获取音频的视频可能无法进行语音识别。较长视频的首次本机识别可能超过 3 分钟。

## 权限与远程代码

- `storage`：保存设置和本地翻译缓存。
- `youtube.com`：读取当前视频字幕并显示字幕层。
- `translate.googleapis.com`：本地翻译不可用时获取在线译文。
- `127.0.0.1:8765`：连接用户主动安装的本机字幕服务。
- 不使用远程代码；所有可执行代码均包含在提交的 ZIP 中。

本扩展没有开发者服务器、广告、分析统计或隐藏功能。本扩展不是 YouTube、Google 或 Microsoft 的官方产品。
